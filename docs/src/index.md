# Hawkes Plastic Networks

[![](https://img.shields.io/static/v1?logo=GitHub&label=Open%20on%20GitHub&message=HawkesPlasticNetworks.jl&color=blue)](https://github.com/dylanfesta/HawkesPlasticNetworks.jl)

!!! warning
    HawkesPlasticNetworks.jl is at an early stage. Its API may change as the
    supported model set grows.

HawkesPlasticNetworks.jl provides explicit building blocks for simulating
spiking networks driven by Hawkes processes. Start with the worked example
below; the API index lists the currently available components.
